## 制作与音轨说明

- **完整介绍：**本项目制作。配乐 A 由介绍片工程的 `score.py` 以 NumPy 合成，未读取外部歌曲、采样或人声；已核对上传视频中的音轨与工程输出对应。
- **快速预览：**保留用户提供视频的原音轨，音轨的来源与授权依据尚待补充。
- **片中案例：**按对应案例的作者与出处署名，分别处理原提示词、示意演示和原作的归属。

视频及其音轨本次均未授予新的开源或再分发许可，详细范围见 [署名与使用说明](../../RIGHTS.md)。

后续替换视频时，先上传新文件，再更新主 README 与本页的对应链接。README 中每个视频链接单独成段，便于显示为播放器。
