# 动效词典 · 配方器使用说明书

想做一段动效视频或一个会动的网页，却只会说“高级一点”“流畅一点”？这本词典把效果拆成可观察、可复制的描述。**配方器负责组装提示词；作品仍要由你选用的 AI 工具制作并实际检查。**

[打开配方器](../index.html#composer) · [先看场景配方](../index.html#recipes) · [看 22 条案例](../gallery/index.html)

## 1 分钟上手

1. **选词。**打开 根目录的 `index.html`。第一屏是品牌首屏：右边播放的是加上一组词做出来的成片，点「把这组词载入配方器」可以直接开始。第二屏的四格流程舞台会自动演示「挑词 → 配方器组装 → 核对分镜 → 出片」，成片默认播放「加上这组词」的版本，可切到「只写内容」对比，也可以换场景。再往下是三条并列的路，词都会进入同一个配方器：
   - 「看滚动 · 滚动解剖」：同一句需求逐层加词，看画面怎么变；结尾可以把示例的 18 个词载入配方器。
   - 「看词库 · 分层词库」：逐层看演示，点**＋ 加入配方器**。筛选条固定在顶部，可按层、按场景配方或按模糊说法筛选。
   - 「看配方 · 场景配方」：选一个最接近目标的场景，点**载入配方器**。每张配方卡顶部有一段 10 秒组合演示：A 只写内容，B 加上这组词；B 播放时，正在起作用的词会在卡片上同步高亮。

   说不清要什么时，看页面最后的「说不清要什么？」：点一句你会说的话（例如「做得高级一点」），原地展开精确写法和对应的词，可以一次全部加入配方器。

   顶部导航就是这条流程：挑词 → 配方器 → 分镜 → 出片，亮起的一步表示你现在所在的位置。已选的词数显示在底部托盘和导航的「配方器」上。载入场景配方会替换已选的词，配方器里可点**撤销**恢复。
2. **配方器第 1 步：做什么，讲什么。**选「视频」或「网页」（载入场景配方时会自动选好），在主题框填入**真实内容**：主角是什么、要讲什么、有哪些已确定的素材或限制。
3. **配方器第 2 步：已选词。**预设词只是起点，移除不合适的词。点任一已选词，预览区会播放这个词的演示；「检查清单」按写提示词要回答的六个问题（形态、主角、运动、驱动、骨架、禁用与验收）提示还缺什么。**做视频时，「驱动」一条可以跳过。**
4. **配方器第 3 步：复制提示词。**选 EN 或中文，点**复制提示词**，粘贴到支持制作网页或代码动效的 Claude 会话。配方器默认要求先给方案再写代码：视频要带时间点的分镜表，网页要按段落列出版式和动效出现的位置。
5. **粘贴之后。**先核对方案是否覆盖你的内容，确认后再让它写代码；然后打开生成的网页，或播放导出的视频，检查文字、镜头节奏、交互和平台画幅。需要发布时，再按目标平台做实际验收。

复制按钮若受浏览器限制，页面会自动选中文本；按 **⌘/Ctrl + C** 即可。选词、形态、主题文字和语言通常保存在当前浏览器的本地存储中；换浏览器或打开方式时，建议先自行保存复制结果。

## 五层怎么选

| 层 | 解决的问题 | 常见选择 |
| --- | --- | --- |
| **L1 底座** | 交付什么、时长画幅、如何稳定渲染与检查？ | 固定舞台、时长与帧率、`seek(t)`、抽帧自检 |
| **L2 质感** | 观众第一眼看到什么、画面有多克制？ | 一个镜头只讲一件事、单一强调色、禁用清单 |
| **L3 运动** | 元素、文字和镜头怎样动？ | 缓动、节拍、转场、镜头运动 |
| **L4 交互** | 网页由什么动作驱动？ | 滚动、指针、状态切换、声音；纯视频可不选 |
| **L5 结构** | 内容按什么顺序展开？ | 分镜表、解说结构、网页段落结构 |

词库有 **75 个词**，场景区有 **10 个起步配方**。点词卡可看实时演示、英文与中文写法、适用场景、避坑和来源；有 A/B 的词可以比较加词前后的差异。想弄懂提示词如何逐层变具体，可先看「滚动解剖」。

## 一个完整例子：15 秒 App 展示片

**目标：**用 16:9 短片介绍一款排周计划的 App。已知内容只有三个功能，不补造用户数字或使用效果。

**主题输入：**`Nimbus 是帮助团队排周计划的 App，本片只展示同步日历、保护专注时段、共享计划三个功能。`

**自行选词：**形态选「视频」；L1 选「固定舞台」「时长与帧率」「seek(t) 纯函数渲染」；L2 选「一个镜头只讲一件事」「禁用清单」；L3 选「慢缓动」；L5 选「分镜表叙事」。L4 留空。选 EN 后，配方器会把主题原文和所选词组装成这样的完整提示词：

```text
Nimbus 是帮助团队排周计划的 App，本片只展示同步日历、保护专注时段、共享计划三个功能。

<direction>
High-end minimal. One idea per shot, lots of empty space.
Banned: bouncy easing, particle bursts, shockwave rings, glows, lens flares, RGB split, camera shake, typewriter text, purple gradients on white, Inter as the display face.
Slow easings (0.9–1.4s). Nothing bounces. Nothing flashes.
</direction>

<structure>
A numbered shot list with timecodes: shot size, camera move and action per shot (e.g. 0–6.4s close-up → pull back, focus shifts).
</structure>

<build>
One self-contained HTML file on a fixed 1920x1080 stage, scaled to fit the window (letterboxed), all CSS and JS inline.
15 seconds at 60fps (900 frames).
Every style is computed from time inside seek(t): no CSS transitions, no timers, no state carried between frames. Expose window.seek(t) and window.DURATION.
</build>

<start>
Show me the plan (storyboard with timings) before writing code.
</start>
```

**接下来：**先检查分镜是否真的覆盖三个功能、每个镜头是否只讲一件事，再让 AI 实现。若改成竖屏视频，要换掉 16:9 舞台要求，并重新检查安全区；配方器只提示少数明显冲突（视频与网页用词混用、缓动方向相反），不会替你协调其他冲突。切换 EN／中文只改变词条写法和结尾语句，**不会翻译你输入的主题**。

## 看懂预览与实际结果

- 配方卡的组合演示用抽象的几何与排版（配虚构字样 Nimbus、HALDEN 等）展示这组词叠加后的节奏与质感，是示意实现，不代表模型对你的主题一定做出同样画面。
- 配方器右侧的预览播放的是现成演示：来自场景配方时是该配方的 10 秒组合演示，点某个已选词时是这个词自己的演示。它们都不使用你填入的主题。
- 「检查清单」提示六个问题中哪些还没回答，**不是质量评分**；是否需要交互词、禁用清单或更多词，取决于作品目标。
- 词典由 [动效片库的 22 条案例](../gallery/index.html)提炼。案例预览与本页小演示都是示意实现；原作者提示词及出处应以片库详情为准。复制出的组合是新的创作指令，不保证模型必然做出示例效果。
- 本地网页可直接双击打开；部分字体与 3D 演示依赖网络。离线时词条和配方仍可阅读，相关演示可能降级。
